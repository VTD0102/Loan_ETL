2.Vai trò Gold layer

2.1. Trách nhiệm

  • Feature engineering nâng cao — tính log, ratio, flag từ silver columns.
  • Aggregate từ bảng quan hệ — JOIN bronze.bureau_raw và bronze.previous_application_raw để có history features.
  • Encode categorical — group + ordinal cho rating/education.
  • Missing indicator flags — tạo các cột *_missing_flag cho ML model học pattern missingness.
  • Analytical views — tạo view cho admin dashboard (distribution, default rate by segment).

4.Feature engineering chi tiết

4.1. Aggregate từ previous_application

prev_stats AS (
    SELECT SK_ID_CURR::TEXT AS member_key,
           COUNT(*) FILTER (WHERE NAME_CONTRACT_STATUS='Approved')::INT AS num_previous_loans,
           ROUND(COUNT(*) FILTER (WHERE NAME_CONTRACT_STATUS IN ('Refused','Canceled'))
                 / NULLIF(COUNT(*),0), 4) AS previous_default_rate
    FROM bronze.previous_application_raw
    GROUP BY SK_ID_CURR
)

Lưu ý: previous_default_rate là proxy — đếm tỷ lệ Refused/Canceled (không phải default thực). Vẫn có signal vì khách hàng bị refuse nhiều lần thường rủi ro cao.

4.2. Aggregate từ bureau

bureau_stats AS (
    SELECT SK_ID_CURR::TEXT AS member_key,
           COUNT(*)::INT AS num_bureau_records,
           COUNT(*) FILTER (WHERE CREDIT_ACTIVE='Active')::INT AS num_active_credit,
           COALESCE(SUM(AMT_CREDIT_SUM_OVERDUE), 0)::NUMERIC AS total_overdue_amount,
           COALESCE(MAX(CREDIT_DAY_OVERDUE), 0)::INT AS max_credit_overdue_days,
           MAX(CASE WHEN CREDIT_ACTIVE='Bad debt' THEN 1 ELSE 0 END) AS has_bad_debt
    FROM bronze.bureau_raw GROUP BY SK_ID_CURR
)

4.3. Dynamic threshold cho high_dti_flag

Threshold 0.35 (chuẩn US) làm 99.7% rows HC có flag = 1 (DTI HC thường cao do AMT_ANNUITY tính theo công thức khác). Fix: compute P75 từ chính data → flag = (DTI > P75). 

dti_threshold AS (
    SELECT quantile_cont(debt_to_income_ratio, 0.75) AS p75
    FROM silver.home_credit_cleansed
    WHERE debt_to_income_ratio IS NOT NULL
)
-- sau đó: CASE WHEN debt_to_income_ratio > d.p75 THEN 1 ELSE 0 END AS high_dti_flag

4.4. Term buckets cân bằng

HC term liên tục 12–45 (tính từ credit/annuity). Không có 12/36/60 fixed như Prosper. Bucket cân bằng theo phân phối thực:

BucketĐiều kiệnTỷ lệ rows
term_12_flagterm ≤ 18~34%
term_36_flag19 ≤ term ≤ 25~37%
term_60_flagterm ≥ 26~29%

4.5. Education ordinal mapping

CASE NAME_EDUCATION_TYPE
    WHEN 'Academic degree'               THEN 5
    WHEN 'Higher education'              THEN 4
    WHEN 'Incomplete higher'             THEN 3
    WHEN 'Secondary / secondary special' THEN 2
    WHEN 'Lower secondary'               THEN 1
    ELSE NULL
END AS education_ordinal

4.6. Credit score band (US FICO classification)

CASE
    WHEN credit_score_midpoint < 580 THEN 'Poor'
    WHEN credit_score_midpoint < 670 THEN 'Fair'
    WHEN credit_score_midpoint < 740 THEN 'Good'
    ELSE 'Excellent'
END AS credit_score_band
