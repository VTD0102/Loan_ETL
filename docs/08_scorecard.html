Lưu ý quan trọng

LR Scorecard không train với class_weight="balanced" — vì sẽ ép probability về 0.5 → score range bị nén lại còn ~200 điểm. Để giữ probability calibrated tự nhiên (mean ≈ default rate thực 8%), bỏ class_weight. Tradeoff: recall lớp Default thấp, nhưng scorecard không dùng cho decision nên không quan trọng.

3.Công thức FICO PDO

3.1. Công thức gốc

PDO = Points to Double the Odds. Mỗi lần odds_good gấp đôi → điểm tăng PDO. Công thức:

score = base_score − (PDO / ln 2) × (logit − base_logit)

3.2. Các tham số project sử dụng

Tham sốGiá trịÝ nghĩa
base_score600Điểm trung tâm (median FICO ≈ 700, dataset HC default rate cao hơn nên thấp hơn)
base_odds_good50Odds 50:1 (good:bad) tại điểm 600 — chuẩn FICO
PDO20Odds_good gấp đôi → +20 điểm
SCORE_MIN300Floor

factorPDO / ln 2 ≈ 28.854Constant tính trước

3.3. Hàm chuyển đổi (Python)

def prob_to_score(p):
    p     = np.clip(p, 1e-9, 1 - 1e-9)
    logit = np.log(p / (1 - p))
    score = BASE_SCORE - _FACTOR * (logit - _BASE_LOGIT)
    return np.clip(np.round(score), 300, 850).astype(int)

6.3. Inference flow (kế hoạch backend)

def get_credit_score(user_id):
    # 1. Look up user features từ gold.hc_features_v1
    row = gold.lookup(user_id)

    # 2. Build input DataFrame với 25 features
    X = pd.DataFrame([row])

    # 3. Predict probability + transform sang score
    prob  = artifact["pipeline"].predict_proba(X)[0, 1]
    score = prob_to_score(prob)

    # 4. Compute breakdown từ contribution table
    breakdown = compute_breakdown(X, artifact["contribution_table"])

    return {"credit_score": score, "breakdown": breakdown, "default_prob": prob}
